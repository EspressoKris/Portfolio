# Kristian Gurashi — academic website

Source for **[espressokris.github.io/Portfolio](https://espressokris.github.io/Portfolio/)**: research and publications of Kristian Gurashi, computational biologist at the MRC Weatherall Institute of Molecular Medicine, University of Oxford.

Built with [Jekyll](https://jekyllrb.com) on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template (a fork of Minimal Mistakes) and published with GitHub Pages.

## Where things live

| What | File |
| --- | --- |
| Homepage (intro, research, selected papers) | `_pages/about.md` |
| Experience, education, awards | `_data/cv.yml` (homepage timeline and highlights) |
| Publications | `_publications/*.md`, one file per paper |
| Blog posts | `_posts/*.md` |
| Sidebar profile and links | `author:` block in `_config.yml` |
| Top navigation | `_data/navigation.yml` |
| Site styles, light and dark colours | `_sass/_custom.scss` (CSS variables at the top) |

## Adding a publication

**1. Create the page from the DOI** (no extra packages needed):

```bash
python3 scripts/new_publication.py 10.1016/j.xcrm.2025.101933 --image ~/Downloads/graphical_abstract.jpg --featured
```

This fetches the title, journal, date, volume, pages, authors (your name in bold, first-author detected) and abstract from Crossref, copies the image into `images/GraphicalAbstracts/`, and writes `_publications/YYYY-MM-DD-title.md`. Options: `--image` (graphical abstract), `--code <url>` (code repository), `--featured` (show on the homepage).

**2. Open the new file and fill in the two `TODO` lines:**

- `excerpt:` one sentence on the main finding (shown on cards and used by search engines)
- `keywords:` comma-separated; these feed the word cloud

Optionally add a `## Key findings` bullet list above the summary.

**3. Commit and push.** The build makes the thumbnail and refreshes the word cloud automatically.


The citation, buttons and PlumX metrics are generated from these fields.

## Automatic images

`scripts/build_assets.py` makes `images/GraphicalAbstracts/thumbs/*.jpg` and `images/wordcloud.png` from your publications. The GitHub Actions workflow (`.github/workflows/jekyll.yml`) runs it on every push before building the site, so nothing needs to be generated by hand.

This requires **Settings → Pages → Build and deployment → Source: GitHub Actions**. To preview the images locally:

```bash
pip install -r scripts/requirements.txt
python3 scripts/build_assets.py
```

## Running locally

With Docker (no Ruby install needed):

```bash
docker run --rm -p 4000:4000 -v "$PWD":/srv/site -v portfolio_bundle:/usr/local/bundle -w /srv/site ruby:3.3 \
  bash -c "bundle install && bundle exec jekyll serve --host 0.0.0.0 --force_polling --destination /tmp/_site"
```

Then open <http://0.0.0.0:4000/Portfolio/>. Changes to `_config.yml` need a restart.

Or with Ruby 3.x installed: `bundle install && bundle exec jekyll serve`.
