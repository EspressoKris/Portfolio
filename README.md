# Kristian Gurashi — website

Source for **[espressokris.github.io/Portfolio](https://espressokris.github.io/Portfolio/)**: research, publications, tutorials and writing by Kristian Gurashi, computational biologist at the MRC Weatherall Institute of Molecular Medicine, University of Oxford.

Built with [Astro](https://astro.build); the tutorials use [Starlight](https://starlight.astro.build). Deployed to GitHub Pages by `.github/workflows/deploy.yml`.

## Where things live

| What | Where |
| --- | --- |
| Homepage | `src/pages/index.astro` |
| Interactive cell map | `src/components/CellMap.astro` (simulated data) |
| Name, links, experience, education, awards, research areas, menu | `src/data/profile.ts` |
| Publications (one file per paper) | `src/content/publications/*.md` |
| Graphical abstracts | `src/assets/abstracts/` (resized automatically) |
| Blog posts | `src/content/blog/*.md` |
| Tutorials | `src/content/docs/tutorials/**` (Markdown or MDX) and the `sidebar` in `astro.config.mjs` |
| Colours, fonts, light/dark | `src/styles/global.css` (tutorials: `src/styles/starlight.css`) |

## Adding a publication

```bash
npm run new-pub -- 10.1016/j.xcrm.2025.101933 --image ~/Downloads/abstract.jpg --featured
```

This fetches the details from Crossref (title, journal, date, volume, pages, authors with your name in bold, abstract), copies the image, and writes `src/content/publications/YYYY-MM-DD-title.md`. Then fill in the two `TODO` lines:

- `excerpt:` one sentence on the main finding (cards and search engines)
- `keywords:` comma-separated; these feed the topic filters and the word cloud

Commit and push. Thumbnails are generated by Astro and the word cloud by the deploy workflow.

## Adding a tutorial

Create a Markdown file under `src/content/docs/tutorials/` with a `title:` in its front matter, then add it to the `sidebar` in `astro.config.mjs`. Starlight components (asides, tabs, cards, steps) are available in `.mdx` files: see the [Starlight docs](https://starlight.astro.build/components/using-components/).

## Running locally

Needs Node 22.23 or newer.

```bash
npm install
npm run dev
```

Open <http://localhost:4321/Portfolio/>. `npm run build` makes the production site in `dist/`.

To refresh the word cloud locally (optional; CI does it):

```bash
pip install -r scripts/requirements.txt
npm run wordcloud
```
